# Changelog

## 16001-0.1.3

- Upgrades: with a zone picked, each item shows its rank for the slot after its name.

## 16001-0.1.2

- Zone filter: one search box in place of the Zone button and list. "Anywhere", "Current zone", then all zones by name. Type to search.

## 16001-0.1.1

- The spec is read from your talents: the tree with the most points. Before, a new install started on the first spec of the class.

## 16001-0.1.0

First release.

- Ranked upgrades per slot for your class and spec, with sources.
- Item tooltips: rank, gain, stat changes against the equipped item, best suffix, recommended enchant, source.
- Upgrade arrows on quest rewards, loot and vendors.
- Wanted drops on creature tooltips, map pins, tracker, guide arrow.
- Simulator with custom stat weights.
- Wishlist, loot history, luck stats.
- Roll window with upgrade hints, off by default.
