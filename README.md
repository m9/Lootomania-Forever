# Lootomania

## Gear upgrades, loot sources and loot rolls for WoW Forever

- Ranked upgrades per slot for your class and spec, with where to get each item.
- Item tooltips: rank, gain against what you have equipped, stat changes, best suffix, recommended enchant, source.
- Upgrade arrows on quest rewards, loot and vendors.
- Wanted drops on creature tooltips, map pins, a tracker and a guide arrow.
- Simulator for any class, spec and level, with custom stat weights.
- Wishlist, loot history and luck stats.
- Roll window with upgrade hints. It is off at first: tick "Enabled" under "Roll window" in the settings.

## Commands

- `/lm`: window. The minimap button opens it too.
- `/lm help`: all commands.
- `/lm upgrades`, `/lm sim`: upgrades, simulator.
- `/lm spec <name>`: spec used for ranking.
- `/lm track <item link>`, `/lm untrack <item link>`: tracker.
- `/lm wish <item link>`: wishlist.
- `/lm rolls`, `/lm rolls test`: roll window, sample rolls.
- `/lm minimap`: minimap button on/off.

## Install

Unpack `Lootomania-<version>.zip` from the [releases page](https://github.com/m9/Lootomania-Forever/releases) into `_forever_\Interface\AddOns`.

WowUp: Install from URL, `https://github.com/m9/Lootomania-Forever`.

## Data

- Item stats, crafting, enchants and bosses: the game client's own tables.
- Drop, vendor and quest sources: [QuestieDB](https://github.com/Questie/QuestieDB).
- Vendor currency costs and reputation requirements: [AllTheThings](https://github.com/ATTWoWAddon/AllTheThings).
- Seen loot, vendor prices and quest rewards: collected in game by the addon.
